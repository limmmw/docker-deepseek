# running deepseek AI on ubuntu server using docker container

- download the repo:
    ```bash
    git clone https://github.com/limmmw/docker-deepseek.git
    cd docker-deepseek
    ```
- run: 
    ```bash
    docker-compose up -d
    ```
- access ```http://localhost:3000```

- stop:
    ```bash
    docker-compose down
    ```
